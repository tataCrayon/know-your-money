# 市场地图 · 采集工具与数据说明

这个目录存放「跨市场全景」那篇分析（`notes/analysis/2026-10-31-市场全景-知识库.md`）的**数据底座**：一个采集脚本、一份可复现的快照、一份逐源成败日志。

目的只有一个：**让"市场全景"里的每个数字都能被重新算一遍**。数字不能复现，分析就只是叙事。

## 目录

```
市场地图/
├── README.md                      # 本文件
├── scripts/
│   └── collect_snapshot.py        # 采集脚本（单文件，无自定义依赖）
└── data/
    ├── snapshot-2026-10-30.json   # 快照（按交易日命名）
    ├── manual-2026-10-30.json     # 手工兜底：全球指数读数（见下文「接口不稳」）
    ├── manual-lg-2026-10-30.json  # 手工兜底：乐咕估值读数（见下文「接口不稳」）
    └── collect.log                # 逐源 OK / ERR 与耗时
```

## 怎么跑

```powershell
# 在仓库根目录
$env:PYTHONIOENCODING="utf-8"
python 市场地图/scripts/collect_snapshot.py
```

- 输出：`data/snapshot-<交易日>.json`（约 40 KB），同时在 `data/collect.log` 追加逐源日志。
- 耗时：顺利时 3–5 分钟；东财接口不听话时会到 10 分钟以上（脚本内建重试）。
- 依赖：`akshare`、`pandas`、`requests`（见仓库 README 的环境说明）。**没有自建库、没有数据库、没有 API Key。**

## 已知的接口状况（2026-10 实测）

**能稳定用的**

- 新浪 `hq.sinajs.cn`：A股指数/ETF/个股（`sh`/`sz` 前缀）、港股（`hk`）、美股个股（`gb_`）、外汇（`fx_s*`）、美元指数（`DINIW`）、外盘商品（`hf_*`）、REITs（`sh`/`sz` 代码）。需要 `Referer: https://finance.sina.com.cn`，返回 GBK。
- CBOE VIX CSV、blockchain.info/ticker、中证指数官网估值、乐咕乐股估值分位、集思录转债。

**但"稳定"要打引号的地方**：中证官网 `stock_zh_index_value_csindex` 只返回**20 个交易日**（2026-10-05 ~ 10-30），所以中证口径**做不了任何分位**，只能取当期值；乐咕是**月频**，10 年窗口的样本量取决于指数成立时间（中证1000 只有 145 个月）。两个源的"历史"根本不是一个量级。

**不稳 / 已废弃的**

- **东财 `push2.eastmoney.com/api/qt/ulist.np/get`**：本仓库最痛的依赖。2026-10-31 采集时段**成功率约 1/8**，且表现为 `RemoteDisconnected`（不是超时、不是 4xx）。脚本里 `em_ulist()` 最多重试 20 次、间隔递增。**这是全球指数读数唯一可得的实时源**，所以做了手工兜底。
- 东财 `api/qt/stock/get`：间歇可用，字段需要 `ut=fa5fd1943c7b386f172d6893dbfba10b`。
- 东财历史 K 线 `push2his.../kline/get`、板块列表 `clist/get`：本次全部被拒。
- **乐咕乐股 `legulegu.com`**：**间歇性 504**（Tengine 网关超时，最严重时连首页都打不开）。2026-10-31 当天观察到三段状态：早段约 1/3 成功率（靠重试能拿到）、18:30–19:20 前后全站 504（连续 30+ 次失败）、19:31 之后恢复（0.4s 返回）。所以**必须靠重试，且必须有兜底**：`manual-lg-<交易日>.json`。注意 `上证50` 即使在站点正常时也拿不到（接口可能已下架该指数）。
- **中基协 `amac_fund_abs`**（ABS 备案）：`RemoteDisconnected` 与成功交替，需要重试 3–4 次（单次耗时可达 200s+）。`amac_manager_info`（私募管理人）同一毛病。
- 新浪全球指数历史 `index_global_hist_sina`：只认特定中文名，试过的 5 个全部 `KeyError`。**日/欧/新兴的年内涨跌与估值分位因此不可得。**
- 百度港股估值 `stock_hk_valuation_baidu`：`KeyError: 'chartInfo'`。
- yfinance：Yahoo 返回 403，不可用。
- CoinGecko / Binance：不可用，加密只有 BTC 一个样本。

## 手工兜底：`manual-<交易日>.json` 与 `manual-lg-<交易日>.json`

当实时接口整体不可用时，采集器会读兜底文件并合并进快照，同时在快照里写 `_fallback` 字段（含文件名、抄录时间、原始来源）。

| 文件 | 谁读它 | 兜的是什么 |
|---|---|---|
| `manual-<交易日>.json` | `collect_global_equity()` | 全球指数读数（东财 `ulist` 成功率约 1/8） |
| `manual-lg-<交易日>.json` | `collect_cn_index()` 的乐咕段 | 三个宽基的 PE/PB 与分位（`legulegu.com` 会整站 504） |

**它们不是"补数"，是"抄录"**——只允许填**本次会话中真实成功请求到**的读数，并注明抄录时间。任何推测值都不许进这两个文件。

格式（全球指数）：

```json
{
 "trade_date": "2026-10-30",
 "captured_at": "2026-10-31 17:20 (Asia/Shanghai)",
 "source": "eastmoney push2 /api/qt/ulist.np/get (secid 100.XXX)",
 "jp": {"N225": {"name": "日经225", "last": 63290.11, "chg1d": -2.12}},
 "eu": {...},
 "em": {...}
}
```

格式（乐咕估值，注意 `_meta` 里必须写明**频率**与**分位窗口**）：

```json
{
 "_meta": {"captured_at": "...", "frequency": "月频", "percentile_window": "full_history_not_10y", ...},
 "000300": {"name": "沪深300", "pe_ttm_lg": 12.17, "pe_pct_all": 42.5, "pe_all_n": 259, ...}
}
```

## 分位数的窗口约定

乐咕这份序列是**月频**，沪深300 只有 259 行、2014 年上市的中证1000 只有 145 行。原代码用 `tail(2500)` 想取"10 年"，月频永远取不满 → 实际拿到的是**全历史**。

现在 `lg_percentiles()` 显式计算三档并同时输出样本数：

| 输出字段 | 含义 |
|---|---|
| `pe_pct_all` / `pb_pct_all` | 全历史分位 |
| `pe_pct_10y` / `pb_pct_10y` | 近 10 年分位（月频约 120 个样本） |
| `pe_pct_5y` / `pb_pct_5y` | 近 5 年分位（约 60 个样本） |
| `pe_lg_n` / `pe_lg_start` | 序列总样本数与起点，用来判断窗口够不够长 |

**写报告时必须连窗口和样本数一起写**。同一个 QVIX 20.22，1 年窗口分位 70%、10 年 42.6%、全历史 37.5%——不报窗口的分位数字等于没说。

## 改脚本时的约定

1. **取不到就写 `null`，绝不补数、绝不插值。** 报告里对应位置标「未核实」。
2. 每个采集器都包 `safe(name, fn, default, retries)`，务必给它一个**唯一名字**——`collect.log` 靠这个名字定位失败源。
3. `series_stats()` 是唯一的统计口径来源（5/20/60/120 日、年内、近1年、距250日高、20/60 日年化波动）。新增指标请加在这里，不要在采集器里另算一套。
4. 新增市场时同步更新：本 README 的「快照结构」表 + `notes/analysis/2026-10-31-市场全景-知识库.md` 的对应章节。
5. 别把 `data/*.json` 当成"历史数据库"。它们是**单日快照**，按交易日命名，用于复现那一篇分析。要时序请另建。

## 数据边界

- 快照里所有行情是**上一个交易日收盘**（脚本按运行日判断，周六日会标注）。
- 宏观是月报，天然滞后 1–2 个月，`macro` 段每项都带自己的 `month`/`date` 字段。
- 快照**不含**：实时盘口、逐笔、ETF 溢价明细、港股 PE、银行理财收益率、IPO 破发率、大多数商品的历史序列。
