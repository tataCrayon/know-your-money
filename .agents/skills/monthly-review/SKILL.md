# 月度复盘技能

## 复盘流程

1. **收集**：读取 `notes/trades/` 与 `notes/lessons/` 中当月全部笔记，以及上月复盘（如有）。
2. **学习进度对照**：对照《投资学习计划.md》的时间线——本月读了什么、学了什么概念、作业完成情况。
3. **操作复盘**：逐笔检查操作笔记中的「预期与验证条件」——哪些被验证、哪些被证伪、哪些还没到验证时间（没到期的不算错）。
4. **行为偏差识别**（重点）：对照当月操作找认知与行为偏差——追热门、频繁操作、理由含糊的操作、冲动操作、该记录没记录的。只描述模式，不做人身评价。
5. **下一步**：给出下月 2~3 个具体的改进项（可执行、可验证），不超过 3 个——改进项多了等于没有。

## 输出

写入 `reviews/YYYY-MM-复盘.md`，结构：

1. 本月概览（学习 + 操作数量，脱敏）
2. 学习进度 vs 计划
3. 操作逻辑验证表（操作 → 预期 → 结果 → 教训）
4. 行为偏差观察
5. 下月改进项（≤3 条）

## 行为规则

- 复盘的对事不对人：表扬具体的正确行为（如「每次操作都写了理由」），批评具体的行为模式而非性格。
- 被证伪的逻辑是复盘的核心产出——帮用户把「错了」转写成「学到了什么、下次检查清单加一条」。
- 涉及收益的讨论一律脱敏（用百分比或只谈逻辑不谈金额），并附「仅个人记录，不构成投资建议」。
- 如果当月没有操作笔记，把「建立记录习惯」本身作为第一条改进项，不做虚构复盘。
