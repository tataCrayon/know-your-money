# 公司分析：四维框架

## 一、生意（Business）

- 这家公司靠什么赚钱？收入结构是什么（一次性/经常性）？
- 客户为什么需要它？如果它明天消失，谁会难过？
- 生意模式在 10 年后还存在吗？被什么颠覆的可能性最大？

## 二、护城河（Moat）

逐项检查，至少确认一条主要护城河：

| 类型 | 判断问题 |
|---|---|
| 无形资产 | 有品牌/专利/牌照让对手无法复制吗？ |
| 转换成本 | 客户换掉它要付出多大代价？ |
| 网络效应 | 用户越多，产品对每个用户越有价值吗？ |
| 成本优势 | 有规模/工艺/地理位置带来的成本壁垒吗？ |
| 有效规模 | 市场是否小到养不活第二个竞争者？ |

- 定量佐证：长期 ROE（>15% 为佳）、毛利率稳定性、定价权（能否随通胀提价）。
- 护城河趋势：在变宽、不变、还是变窄？什么证据支持判断？

## 三、管理层（Management）

- 过去 5~10 年的资本配置记录：分红、回购、并购的质量？
- 管理层薪酬与股东利益是否绑定？
- 年报中「管理层讨论与分析」是否坦诚（是否肯承认错误）？
- 有没有过财务造假、关联交易输送等诚信污点？

## 四、财务（Financial）

- 成长性：营收/净利润 5 年、10 年复合增速
- 盈利质量：自由现金流 vs 净利润的长期匹配度
- 安全性：资产负债率、有息负债、利息覆盖倍数
- 估值：当前 PE/PB 处于自身历史什么分位？（估值是最后一步，不是第一步）

## 输出要求

- 每个维度给出证据（数据 + 来源 + 时间），不确定的标注「未核实」。
- 结论写成「这套生意好在哪、弱在哪」，不写「建议买/卖」。
