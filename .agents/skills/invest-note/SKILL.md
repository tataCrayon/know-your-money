# 投资笔记记录技能

## 判断笔记类型

1. **操作笔记**（买入/卖出/定投/调仓）→ 写入 `notes/trades/YYYY-MM-DD-<标的名>.md`
2. **学习笔记**（读书心得/概念理解/观察记录）→ 写入 `notes/lessons/`（教学类笔记由 invest-lesson 技能负责，本技能负责用户自发的学习记录）

## 操作笔记必填项（用 templates/操作笔记模板.md）

- 操作内容：标的、方向、金额/份额（**金额必须脱敏**：可写比例、定投额定档位如「每月 1 份额」，或直接写「金额私密」）
- 决策理由：为什么买/卖？对应哪条学习到的逻辑？
- 当时环境：市场情况、指数估值位置（可后续补充数据）
- 预期与验证条件：预期什么？出现什么情况说明我错了？
- 情绪状态：是计划内操作还是冲动？恐惧/贪婪/从众占了多大成分？
- 合规声明：固定附「仅个人记录，不构成投资建议」

## 行为规则

- 用户只说「今天买了 XX」时，主动追问缺失的必填项（尤其是「为什么买」和「验证条件」），追问不超过 3 个问题。
- 如果操作理由含糊（如「看涨」「朋友推荐」「热搜」），如实记录，并温和标注「理由待补强——这类理由未来复盘时要重点检查」。
- 不评判操作对错；复盘判断留给 monthly-review 技能按月进行。
- 金额、账户信息一律脱敏；用户提供了具体金额时转写为比例或档位。
