# 信号路由：问题类型 → 信号组合

Step 2（选信号）与 Step 5（权重、矛盾分析）的展开。**先读本文件再动手取数**，否则容易只取到一两个顺手的数据源就下结论。

---

## 一、按问题类型选信号

每种类型给三档：**首选**（境内实测可用且最直接）、**备选**（可用但间接）、**通常不可用**（本机不可达，见 SKILL.md 可用性表）。每类末尾是「最小可用三件套」——环境再差也要凑够三个独立维度。

### 1. 地缘冲突 / 战争风险

- 首选：`akshare_foreign` 黄金（GC）与原油（CL）——避险与冲突成本的直接价格；`eastmoney_sector` 军工与资源板块资金流（资金往哪边站）；`web_search` 查 Polymarket 相关合约概率（二手引用，标注日期）
- 备选：`eastmoney_quote` 黄金 ETF（如 518880，境内交易者的避险定价）、`bis_rates` 相关国家政策利率、`fear_greed` 恐贪指数（避险情绪温度）
- 通常不可用：Polymarket / Kalshi 直连、主权 CDS、战争险保费（都需 web_search 二手取）
- 最小三件套：避险资产方向 + 风险资产方向 + 情绪指标

### 2. 经济衰退 / 宏观周期

- 首选：`akshare_bond`（中国与美国 10Y-2Y 期限结构，境内可达，含倒挂判断与一个月变化）、`bis_rates`（政策利率方向）、`bis_credit_gap`（信贷/GDP 缺口，>10pp 是信用过热警告）、`akshare_foreign` 铜（HG，工业需求晴雨表）与标普期货（ES，风险偏好）
- 备选：`price_history`/`akshare_foreign` 铜金比价（risk-on/off）、`eastmoney_kline` 十年国债 ETF、`worldbank` 长期 GDP 参照（滞后 1-2 年，只做背景）
- 通常不可用：美国财政部官方曲线（时通时不通）、CFTC 持仓
- 最小三件套：期限结构 + 信用扩张程度 + 风险偏好

> 时间尺度提醒：政策利率与信贷缺口是 1-3 年变量，别用它们解释 3 个月内的行情。

### 3. 行业周期 / 泡沫判断

- 首选：`eastmoney_quote` + `eastmoney_fund_flow`（龙头个股的主力 vs 散户）、`eastmoney_sector`（资金在往哪个板块轮动）、`web_search` 查上游设备商订单/VC 集中度
- 备选：`price_history` 行业 ETF 相对大盘的超额、`deribit_futures`（对加密行业）
- 通常不可用：EDGAR 内部人交易（Form 4 集中减持是强信号，但本机不可达）、CFTC 持仓
- 最小三件套：龙头价格趋势 + 资金结构（谁在买）+ 上游/下游验证

### 4. 资产贵不贵（"现在能不能买"）

- 首选：`fear_greed`（情绪位置）、`eastmoney_quote` 该资产的 PE/PB 与换手、`eastmoney_fund_flow`（资金结构）、`akshare_foreign`（黄金/原油/铜/外盘指数期货的绝对价格与趋势）
- 备选：`bis_rates` 作为机会成本锚、`coingecko`（加密资产）、`cn-market-data` 的估值分位（境内指数）
- 通常不可用：期权链 IV（yfinance 间歇）、美债无风险利率
- 最小三件套：绝对估值 + 情绪位置 + 机会成本

> 注意：本技能回答「市场怎么定价」，**不回答「该不该买」**。把结果交给 `market-analysis` 的估值框架，或直接拆成问题让用户自己判断。

### 5. 美股 / 期权 / 崩盘概率

- 首选：`options_chain`（ATM IV、put/call、max pain、隐含波动），前提是 yfinance 通
- 备选：`fear_greed`（合成 VIX 等 7 个信号）、`akshare_foreign` 标普（ES）与纳指（NQ）期货趋势、境内标普/纳指 ETF 的溢价（513500/513100，溢价本身是情绪信号）
- 通常不可用：CFTC 标普与 VIX 期货持仓、Kalshi 的 SPY 区间合约
- 最小三件套：隐含波动 + 情绪 + 防御性轮动（公用事业 vs 可选消费）

### 6. A 股个股 / ETF / 板块

- 首选：`eastmoney_quote`（PE/PB/换手）、`eastmoney_fund_flow`（拆单量级的主力 vs 散户）、`eastmoney_sector`（板块轮动）
- 备选：`eastmoney_kline`（波动率、趋势）、`fear_greed`（外围情绪）
- 通常不可用：Polymarket / Kalshi（没有境外场所给 A 股个股定价）
- 最小三件套：价格与估值 + 资金结构 + 板块相对强弱

> **A 股概率题必须说明局限**：没有预测市场给 A 股个股定价，概率只能从资金流与波动率推演，不能「查」。

### 7. 加密资产

- 首选：`coingecko`（市值、BTC 占比、ATH 距离）、`deribit_futures`（期限结构 contango/back）
- 备选：`deribit_options`（ATM IV 与 put/call 偏斜）、`fear_greed`
- 最小三件套：现货结构 + 期货基差 + 期权隐含波动

## 二、路由三问（逐条筛，三条全过才留下）

| 检查 | 问法 | 淘汰示例 |
|---|---|---|
| 相关性 | 这个信号真能回答这个问题吗 | 问台海局势 → CoinGecko 无法回答 |
| 时间匹配 | 定价期限 = 问题窗口吗 | 问 3 个月 → 世界银行 GDP（滞后 1-2 年）出局 |
| 信息增量 | 有没有独立于已有信号的新视角 | 已有沪深300 行情，再看另一只宽基 ETF 无增量 |

## 三、时间尺度分层

信号按定价期限归组，**不同组的信号不能放进同一票**：

| 尺度 | 典型信号 |
|---|---|
| 短期 0-3 个月 | 恐贪指数、盘中资金流、板块轮动、期权隐含波动 |
| 中期 3-12 个月 | 期权链（长到期）、加密期限结构、周度持仓、内部人交易 |
| 长期 1-3 年 | 政策利率、信贷/GDP 缺口、设备订单、资本开支计划 |
| 超长期 3-10 年 | 人口、GDP 趋势、不可逆的资本配置 |

短期看空 + 长期看多 ≠ 矛盾，可能是 S 曲线拐点。写报告时要明确指出这种「方向对、时机早」的组合。

## 四、权重原则

排序依据是「这条价格背后有没有人真的在承担后果」：

1. **真金白银 > 问卷/观点**：预测市场、期权报价 > 分析师目标价
2. **流动性好的 > 流动性差的**：成交量 < 10 万美元的合约打折看
3. **直接定价 > 间接代理**：直接交易该事件的合约 > 相关资产的相关性推演
4. **高频 > 低频**：日度资金流解释本周，季度信贷缺口解释未来两年
5. **同类信号不重复计数**：三个宽基 ETF 同涨只算「一个」风险偏好信号

## 五、常见矛盾模式库

遇到背离先对照，别急着判对错：

| 模式 | 表现 | 通常的解释 |
|---|---|---|
| 时间错配型 | 恐贪极度恐慌，但信贷缺口显示周期高位 | 短期情绪与中期周期各说各话，两者可以同时成立 |
| 地域错配型 | 人民币走强（资本流入），但 A 股资金流为净流出 | 汇率反映贸易与利差，股市反映风险偏好 |
| 结构错配型 | 指数上涨，但主力资金净流出 | 上涨由散户或被动资金推动，机构在减仓 |
| 定价对象错配型 | 黄金涨（避险），军工 ETF 也涨 | 不是矛盾：同一个风险被两种资产同时定价 |
| 拥挤度型 | 某板块涨幅最大且主力净流入最大 | 可能已拥挤，资金流入是「接盘」而非「吸筹」——需看持续性 |

**背离不是数据错误，是信息。** 找不到解释时，诚实写「本次信号分歧未能归因」，比强行编一个故事好。

## 六、降级路径（境内网络受限时）

### 6.1 三层降级（按顺序，每层都要在报告里标明）

**第 0 层：先确认出口对不对**（最常见的一类"故障"）

境外源（Polymarket、Kalshi、CFTC、SEC、美债、Yahoo、CNN）在境内多被重置，**必须走代理**；境内源（东财、腾讯、新浪、AKShare）**必须直连**，走代理会被对端拒绝。脚本已内置这套路由（`--proxy auto` 读系统代理）。判断方法：

```bash
python scripts/probe_sources.py --proxy none    # 直连基线
python scripts/probe_sources.py                 # 自动代理
```

两组结果对比就知道该走哪条。特别注意两类"假故障"：**CNN 返回 418 是缺浏览器 UA**、**SEC 返回 403 是缺联系邮箱 UA**——都不是网络问题，脚本已按源设置好。

**第一层：换境内可达的等价信号**（最优，因为是同一个价格而非近似）

| 想要的信号 | 境内可达做法 | 实测状态（2026-10-26） |
|---|---|---|
| 国债收益率曲线（中美 10Y-2Y） | `--signals '{"curve":{"type":"akshare_bond"}}'` | ✅ 中债/新浪口径，含倒挂判断 |
| 黄金 / 白银 / 原油 | `--signals '{"gold":{"type":"akshare_foreign","symbol":"GC"}}'`（SI / CL 同理） | ✅ 当日数据 |
| 铜（工业需求） | `akshare_foreign` + `symbol: "HG"` | ✅ |
| 标普 / 纳指期货 | `akshare_foreign` + `ES` / `NQ` | ✅ |
| 境内指数点位、ETF 净值、行业资金流、指数估值分位 | 交给 `cn-market-data` 技能（AKShare 接口） | ✅ 实测可用 |
| A 股个股 K 线 | `eastmoney_kline`（走腾讯，不受东财限流） | ✅ |

**第二层：用境内可交易标的做代理**（近似，必须标注「代理」）

| 想要的信号 | 境外原始 | 境内代理 | 代理的局限 |
|---|---|---|---|
| 黄金避险需求 | `GC=F` | 黄金 ETF（如 518880） | 有溢价/折价与跟踪误差 |
| 白银 | `SI=F` | 白银期货 LOF（如 161226） | 流动性较差 |
| 原油 | `CL=F` | 原油 LOF（如 161129 / 501018） | 溢价常很大，不只是油价 |
| 美债长端利率 | 财政部收益率曲线 | 十年国债 ETF（如 511260） | 反映的是中国利率，不是美国 |
| 标普 500 风险偏好 | `SPY` | 标普 500ETF（如 513500） | QDII 溢价本身是情绪信号 |
| 波动率恐慌 | `^VIX` | 恐贪指数（FearGreed） | 合成指标，非实时 |

**第三层：二手引用**，见 6.2。

这些代码每次都要现场确认（`--preset a-share --symbol <代码>` 看名称与成交额），不要凭记忆写进报告。

### 6.2 二手引用纪律

`web_search` 查到的概率可以引用，但必须同时写清三件事：

1. 来源（哪个平台/哪个页面）
2. 抓取日期
3. 「二手引用，未直接验证」

不许把二手引用当成一手定价数据，也不许用它替代「≥3 独立维度」的要求。

## 七、自定义 spec 示例

```bash
# 衰退判断（境内可用版）
python scripts/oracle_signals.py --signals '{
  "policy_rates": {"type": "bis_rates", "countries": ["US", "CN", "JP"]},
  "credit_gap":   {"type": "bis_credit_gap", "countries": ["US", "CN"]},
  "cn_long_bond": {"type": "eastmoney_kline", "symbol": "511260", "limit": 60},
  "sentiment":    {"type": "fear_greed"}
}'

# A 股个股资金面
python scripts/oracle_signals.py --signals '{
  "quote":  {"type": "eastmoney_quote", "symbol": "600519"},
  "flow":   {"type": "eastmoney_fund_flow", "symbol": "600519", "limit": 10},
  "sector": {"type": "eastmoney_sector", "kind": "industry", "limit": 15}
}'
```

字段与参数详见 `providers.md`；脚本会把每条信号的 `as_of` 与 `horizon` 一并带出，报告直接引用。
