# know-your-money

个人投资学习仓库：**考证 · 学习 · 实践** 三主线并行的全过程留痕。

> 定位：这不是一个"荐股号"，是一份**可复核的学习档案**。
> 每篇分析都标明数据来源与截止日期，每个概念都留自测题与小作业，每次判断都可事后检验。
> 全部内容仅作学习记录与分析练习，**不构成投资建议**。

---

## 三、怎么用

**学一个概念**
```
/invest-lesson 安全边际
```
产出写入 `notes/lessons/YYYY-MM-<概念>.md`，frontmatter 自动带 `首学日期` 与三个复习节点（1 周 / 1 月 / 3 月）。

**分析一个标的**
```
/market-analysis 沪深300
/market-analysis 516670
```
公司走「生意—护城河—管理层—财务」四维；基金走「费用—跟踪误差—规模—基金经理」；指数走「估值分位—盈利趋势—利率环境」。

**读市场怎么定价一件事**
```
/market-oracle 明年美国会不会进入衰退
```
只用交易数据（收益率曲线、盈亏平衡通胀、商品、预测市场、期权），不用新闻当证据。

**记一笔操作**
```
/invest-note
```

**月末复盘**
```
/monthly-review
```

## 四、环境依赖

- **Python 3.11+**，核心取数靠 AKShare（免费、无需 Key）：

  ```bash
  pip install -U akshare pandas requests
  ```

  实测版本：Python 3.11.15 / akshare 1.18.94 / pandas 3.0.5 / requests 2.33.0。
- 部分技能依赖外部服务（东方财富 API Key、Longbridge、Yahoo/yfinance、LaTeX）。缺失时会降级为境内替代源或 Markdown 输出，**不会静默编造数据**。
- 境外数据源需要代理；脚本默认读系统代理，境内源强制直连。

## 五、写作纪律（这个仓库的规矩）

1. **数据可溯源**：每个数字带来源与日期；取不到就写「不可用」，不许凑数。
2. **不给买卖指令**：只给框架与事实，决策与理由由本人做出并留痕。
3. **风险前置**：先讲下行与不确定性，再讲收益可能性。
4. **可证伪**：分析必带「什么出现=我错了」的触发条件。
5. **费曼检验**：教学笔记必须有「我自己的话」一栏，写不出来=还没懂。
6. **免责**：涉及具体标的的输出，结尾必附「仅作学习记录与分析练习，不构成投资建议」。
